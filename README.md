# gargantua

Thème omaLauncher / Omarchy — Interstellar

Trou noir supermassif et son disque d'accrétion, lentille gravitationnelle. Noir absolu + ambre incandescent. Trois cadrages, du plus large au plus serré.

## Install

Settings → Theme → coller l'URL du dépôt :

    github.com/marc26712/omarchy-gargantua

## Contenu

- `colors.toml` — palette (dark)
- `backgrounds/` — 3 fonds 1080×2400 (9:20)
